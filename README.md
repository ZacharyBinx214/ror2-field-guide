# ror2-field-guide

Risk of Rain 2 field guide and run tracker: items, stages, survivors, combos, unlock hunt, scrap advisor and run history. One self-contained page that works offline once opened.

Open https://zacharybinx214.github.io/ror2-field-guide/ in Safari, then Share > Add to Home Screen.

- `index.html` is the whole app (data, fonts and code are inside it).
- `sw.js` and `manifest.webmanifest` give it offline use and a home screen icon.
- Runs and settings are saved in the browser on your device. Use Back up or move your data > Save backup file to keep a copy.
